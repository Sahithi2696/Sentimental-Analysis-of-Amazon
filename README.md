# Sentimental-Analysis-of-Amazon_using_Python
This project analyzes customer reviews to classify opinions as positive, negative, or neutral using Python, NLTK, and scikit-learn. Performed text preprocessing (tokenization, lemmatization, stopword removal) and feature extraction using TF-IDF Vectorization. Using NLP preprocessing and machine learning models like Logistic Regression and Naïve Bayes, the system extracts insights from unstructured feedback, helping businesses improve products, refine marketing strategies, and enhance customer experience. Evaluate model accuracy and performance using sklearn.metrics → accuracy_score, confusion_matrix, classification_report.
